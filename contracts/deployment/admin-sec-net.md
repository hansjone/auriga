# 管理台入口与出网策略边界

`GET /api/org/v1/admin/security/entries` 投影当前安装租户已验证的门户、管理 Origin、实例入口模式和代理种类。可读取 edge 中转配置时，还返回门户同源的 `/ai/v1` 公网入口；不返回内部后端地址、监听器、凭据或硬编码的出口观测。要求管理上下文及 `org.policies.read`。安装配置缺失或租户不匹配时返回 `common.unavailable`。HTTPS 配置不证明在线证书健康。

编辑复用 `/api/org/v1/admin/policies/egress`。服务端要求管理上下文、`org.policies.write`、十分钟内 step-up 和 `If-Match`；缺少前置版本返回 428 / `org.precondition_required`，旧版本返回 412。其他策略键保留原有行为。前端必须确认，不自动重放失败写入。

模式为 `open` 或 `allowlist`。`open` 沿用原有公网出网，再执行平台拒绝项；`allowlist` 只允许命中允许列表的目标，空列表明确拒绝全部。未带模式的旧值：非空有效允许列表按白名单处理，否则按开放处理。管理员可清空平台规则并恢复默认开放。环境拒绝列表和逐 IP 公网校验始终优先，私网、回环、链路本地、CGNAT、元数据地址、非公网 IPv6 均不能放开，拨号固定为已校验 IP。

管理员从未保存的 v1 空种子显示“未配置，沿用默认出网”，不下发收紧策略。egress 冷启动、platform 晚起或不可用时，保持原有环境默认或最后已应用策略；健康检查仅反映监听器，agent 启动不等待平台策略。共享卷从任一容器先初始化均使用相同写入 UID。

新写入仅接受小写 ASCII DNS 名和最左侧 `*.`，拒绝 IP、URL、端口、单标签、内部域名、重复项及未知字段；分类无注册表，只接受空数组。旧值通过只读兼容投影保留有效域名、规范化大小写并忽略不支持项，页面明确提示 `legacyAdjusted`，保存后落为当前格式。V3 迁移为已保存旧值提升版本，避免旧摘要与新版投影发生同版本冲突；未配置种子保持 v1。

文件通道由 `egress.schema.json` 定义。平台独占写策略卷，egress 独占写状态/回报卷，另一方只读；实例不挂卷，不新增网络管理端口。平台版本化发布，egress 持久化后应用，只关闭新策略拒绝的现有隧道。状态从 `GET /api/org/v1/admin/security/egress` 读取，保存、下发和生效版本分别展示。

发布和回报导入分事务。回报绑定租户、节点、版本和摘要；不一致时保留下发记录并持久化失败状态，不冒充生效。合法失败回报允许“已应用版本高于候选版本”，以呈现出口拒绝回退的事实。egress 变化时立即回报，未变化时最多每 30 秒更新心跳；超过 90 秒为过期，页面通过刷新读取。可配置 `AURIGA_EGRESS_TENANT_ID`，在首次快照与状态恢复时绑定预期租户；未配置时沿用安装私有卷的信任边界。

需主控接线：浏览器 TLS 证书到期、实际中转上游代理/公网出口和实时健康观测。Bifrost 继承原有运行环境与提供商配置，本线不覆盖代理环境。当前实现仅支持单宿主、固定安装租户、单共享出口；多节点分发需另行扩展。
