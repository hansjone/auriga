# 0014 服务间通信和身份令牌

- 状态：已采纳
- 日期：2026-10-19

## 背景

浏览器、服务、DSH 实例、用户电脑上的插件、节点代理各自需要不同的身份凭据。

## 决定

对外 REST（OpenAPI 3.1），对内 gRPC，异步 NATS 事件；workspace 与节点代理之间是节点代理主动连接的 gRPC 双向流（mTLS）。浏览器用不透明会话 cookie，edge 校验后换成 iam 签发的 5 分钟访问令牌（JWT）转给服务；服务用 JWKS 自行校验。edge 给 DSH 实例的请求加 Ed25519 签名的短期身份头（带 kid，支持轮换）。实例调平台用实例令牌，插件连接模式用设备凭据（设备授权流程 RFC 8628），节点代理用节点证书。

## 后果

令牌格式、请求头和密钥文件格式写在契约里（`contracts/README.md`、`contracts/plugin`）。
