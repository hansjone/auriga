# ADR 0023：消息网络受限运行签发及 v2 契约

状态：待独立审查。依据：`docs/design/msgnet-auto-renewal.zh.md` 第10节 D1–D5。

每日离线根亲签造成清单过期后停服。采用离线根签 RuntimeAuthority 和独立 RootControl，服务器运行钥仅签 v2 清单、公告、内部传输信任包；业务三用途钥和内部X.509 CA独立。授权显式无硬截止，365天复核只提醒。根撤销须经独立受信渠道逐端持久确认，未确认者隔离，不承诺未送达端获知撤销。

采用24h清单/12h刷新、8天业务钥/5天轮换/48h预告，成熟24h及正常360s重叠。允许携带签名前驱证明的受限restart恢复和过期历史归档；版本和控制代际单调，issued_at允许校正后变早。时钟异常拒签且不记录首发，稳定后自动恢复。内部叶子90天/提前30天，CA10年/提前2年，双信任和实际握手回执后退休旧CA，过期通过安装身份HPKE密封引导。

新增v2 schema、OpenAPI、NodeControl消息及共享向量，字段和完整语义见 `contracts/network/auto-renewal-v2.md`。v1冻结，仅一次迁移核验；在线端先升级，根签承诺许可后最多10分钟冻结，同事务屏障禁用旧队列，屏障后仅向前恢复。耐久消息保留原TTL和ID重新封装并去重。

代价：服务器入侵可在本realm持续造清单、业务钥和内部CA信任包，直到根撤销经独立渠道送达并隔离；用户已接受此取舍。没有运行钥再委托、在线根、授权年度停服或跨域签发能力。实施须由C/N/P/I/O/D分别落地并经正常用户入口验收，本ADR及契约本身不代表已部署。
