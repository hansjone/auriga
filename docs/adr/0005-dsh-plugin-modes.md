# 0005 DSH 插件三种模式、独立发布

- 状态：已采纳
- 日期：2026-10-19

## 背景

团队成员既有在平台服务器上的实例，也有自己电脑上的 DSH；也有人只想要一个带企业登录的单机 DSH。

## 决定

插件单独发布到 npm（包名 `auriga-dsh`，MIT），三种模式：离线版 standalone（应急账号 + 身份源连接器，不连平台）、托管 managed（平台上的实例）、连接 connect（用户电脑接入平台）。插件只做必须在 DSH 进程里做的事；团队界面由平台提供、插件挂载；团队工具经 ai-gateway 的 MCP 提供。

## 后果

插件和平台之间的协议带版本号，平台同时支持当前和上一个大版本（见插件协议契约）。
