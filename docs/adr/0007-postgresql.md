# 0007 PostgreSQL：内置或外置，每服务一个 schema

- 状态：已采纳
- 日期：2026-10-19

## 背景

要同时支持离线单机安装和企业已有数据库；以后可能做 SaaS。

## 决定

数据库只用 PostgreSQL。内置模式随安装包带 PostgreSQL 17、只听 127.0.0.1:15433；外置模式要求 ≥ 15。每个服务一个 schema 和一个数据库角色，只授予自己 schema 的权限；Flyway 迁移遵循"先扩后缩"。所有业务表从第一天起带 `tenant_id`，MyBatis-Plus 租户插件 + 行级安全（RLS）双重保证。主键用应用生成的 UUIDv7，时间用 `timestamptz`。敏感字段应用层加密。

## 后果

单租户私有部署也付出 `tenant_id` 的成本，换来以后多租户不用迁移数据。
