# 0012 身份源通用架构：平台核心 + 连接器 + 步骤协议

- 状态：已采纳
- 日期：2026-10-19

## 背景

要支持团队账号、企业自建认证、标准协议（OIDC、SAML、LDAP）和微信等平台，开源后别人也要能接自己的系统。

## 决定

账号与身份分开（一个账号可绑定多个身份）。连接器只把外部协议翻译成 ExternalProfile，不碰数据库、不发会话；找账号、准入、多因素、发会话由平台核心统一处理。登录过程表示成一串步骤（redirect / qr / form / webauthn / device / done / fail），前端只认步骤类型。连接器可以是 Java 插件（ServiceLoader）或任意语言的远程 HTTP 服务。团队账号和应急账号是内置连接器；企业定制连接器放各企业自己的仓库。

## 后果

加新身份源不用改登录页和平台核心；需要一套连接器测试套件（TCK）保证第三方实现的质量。
