# 0010 Windows 上用原生进程运行实例，隔离弱于容器

- 状态：已采纳
- 日期：2026-10-19

## 背景

Windows 服务器上通常没有容器运行时，但不少团队只有 Windows 服务器。

## 决定

Windows 部署用原生进程驱动：每实例一个本地账号 + 垫片进程 + Job Object + 目录 ACL + WFP 按 SID 过滤出站 + NTFS 配额。隔离强度低于容器，面向互相信任的团队；对外开放的部署走 Linux + 容器。AppContainer 作为可选的强隔离，待验证（S3）。

## 后果

Windows 上实例能读系统公共目录；文档里要写清隔离边界。S3 的验证结论补充进本 ADR 或新 ADR。
