# 0003 服务按模块拆分，部署时可合并

- 状态：已采纳
- 日期：2026-10-19

## 背景

私有部署多是几十人的团队，跑 8 个 JVM 太重；大规模时又需要独立扩容。

## 决定

每个 Java 服务拆成 `api` 和 `impl` 两个 Maven 模块，别的服务只能依赖 `api`。`platform-app` 把选中的模块装进同一个 JVM；合并部署时 `api` 由本地 Bean 实现，分开部署时换成 gRPC 客户端，由启动配置选择。事件两种部署下都走 NATS。ArchUnit 在 CI 里强制检查依赖规则。

## 后果

单机版只跑一个 Java 进程（约 0.6–1 GB）；同一份代码支持集群部署。模块间不能共享表、不能调用对方内部类。
