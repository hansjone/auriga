# 必备参数与保管清单

本页给现场部署和开发的人：哪些东西必须自己准备，哪些东西生成后必须永久保管。命令的完整步骤见 [DEPLOY.md](../../DEPLOY.md)（只部署）和 [MAINTAIN.md](../../MAINTAIN.md)（改代码并自己构建）。

> **⚠ 安装完成后立即对照第二节，把能导出的材料导出并放到离线介质。** 其中应急口令只在私密终端显示，站点构建私钥和离线降级私钥没有再生命令，丢了只能换新的。

下文以默认数据目录为例：`--data /srv/auriga` 实际落在 `/srv/auriga/auriga-data`（规则见第一节“数据目录”）。

## 二、必须永久保管的材料

“能否恢复”一栏里，“能”指现场有办法找回或重建，不代表没有后果。冷备份指 `sudo ./auriga backup` 或升级前自动做的备份，位置见本节“auriga-backups”一行。

| 材料                                                               | 在哪一步产生                                                                                    | 文件位置                                                                                                                                                                | 谁保管、放哪                                                                                                                      | 丢失后果                                                                                                                                   | 能否恢复                                                                                                                                                                                                                                                                            |
| ------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 应急账号口令和 TOTP 密钥                                           | `install`（平台首次 seed 后）。只在私密交互终端显示；终端被重定向时不显示，只提示去私密终端查看 | 原始凭据在 `<数据目录>/enrollment/emergency-enrollment.json`（私有目录）。显示后留下不含凭据的标记 `.emergency-displayed`                                               | 现场管理负责人。口令放密码管理器，TOTP 密钥导入验证器并另存离线副本。不要在共享或录屏的终端查看                                   | 无法用应急账号登录管理台。若没有别的管理员，无法进入管理台邀请成员                                                                         | 能：只要上述文件或冷备份还在，可在安装目录的私密终端用 root 执行 `sh deploy-nas/scripts/emergency.sh show` 读出原始安装凭据（不要管道或重定向输出；说明见 [deploy/nas/README.md](../../deploy/nas/README.md) “需要再次查看时”）。该命令不验证凭据当前是否有效，平台尚无应急轮换实现 |

### 安装完成后的导出动作

1. 在私密终端确认已记下应急口令和 TOTP，并把 TOTP 导入验证器。
2. 把 `resource-roots.json` 原字节拷到桌面构建机（需要桌面客户端时）。
3. root 把 `downgrade.pk8` 导出到离线介质。
4. 执行 `sudo ./auriga backup`，把 `auriga-backups` 里的归档和 `.sha256` 拷到离线介质。
5. 记下站点构建公钥指纹，并把站点构建私钥备份到离线介质。

## 三、默认参数在哪查

最直接的办法：运行 `./auriga --help` 看全部命令，`./auriga <命令> --help`（或 `./auriga help <命令>`）看该命令每个参数的说明和默认值，不需要 sudo。下表是常用参数速查，以命令行帮助为准。

`install` 完成后会打印“⚠ 请立即保管以下材料”清单，并在数据目录写一份不含任何口令或私钥内容的 `INSTALL-SUMMARY.txt`，记录访问地址、发行公钥指纹和上表各材料的位置；重复执行 `install` 会刷新它。

| 命令                                                    | 常用参数与默认值                                                                                                                                                                                                                                                                        |
| ------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `verify <文件或目录>`、`unpack <tar或首卷或parts.json>` | `--verify-key`、`--trust-fingerprint`（二选一固定发行身份）、`--allow-unsigned`（默认关）；`unpack` 必须有 `--out <全新目录>`                                                                                                                                                           |
| `devkit verify [套件目录]`                              | `--version`（默认当前源码版本）、`--source`（默认 `.`）、`--verify-key`；省略套件目录时读源码根的 `.auriga-devkit.json`                                                                                                                                                                 |
| `devkit merge <增量包>`                                 | `--kit` 必填，`--verify-key`                                                                                                                                                                                                                                                            |
| `changes export` / `changes apply <补丁.tar>`           | `export` 必须有 `--out`，且在源码目录之外                                                                                                                                                                                                                                               |
| `doctor --build`                                        | `--memory-mib` 4096、`--cpus` 2。实际门禁要求可用内存不少于 5120 MiB（工具容器上限加预留的 1024 MiB）                                                                                                                                                                                   |
| `bundle`                                                | `--build` 关、`--offline` 关（必须与 `--build` 同用）、`--sign-key`（离线构建必填）、`--version`（默认见上表）、`--out`（默认 `auriga-offline-<版本>.tar`）、`--memory-mib` 4096、`--cpus` 2、`--install` 关、`--data` `/srv/auriga`、`--release` `auriga-release.json`（维护者发行用） |
| `keygen site`                                           | `--out` 默认 `site-build-key`，目录须全新                                                                                                                                                                                                                                               |
| `trust add-site-key <pem>`                              | `--confirm-fingerprint` 64 位小写指纹必填，`--data` `/srv/auriga`                                                                                                                                                                                                                       |
| `trust remove-site-key <指纹>`                          | `--data` `/srv/auriga`                                                                                                                                                                                                                                                                  |
| `install`                                               | `--address`、`--domain`、`--proxy` 三选一；`--data` `/srv/auriga`；`--verify-key`、`--trust-fingerprint`；`--allow-unsigned` 关；`--package`（用引导程序直接装 tar 或首卷）；`--desktop-*` 三项                                                                                         |
| `upgrade <新包>`                                        | `--data` `/srv/auriga`、`--allow-unsigned` 关                                                                                                                                                                                                                                           |
| `doctor`、`backup`、`status`、`stop`、`logs`            | `--data` `/srv/auriga`；`logs` 输出最近 100 行并带时间戳                                                                                                                                                                                                                                |

`--allow-unsigned` 只用于显式的紧急缺签名例外，会打印警告并被永久记入安装状态，`doctor` 持续报 FAIL，不要作为日常参数。需要它之外的完整参数，直接看对应的 Go 源码文件：`install.go`、`bundle.go`、`trust.go`、`locks.go`、`build_budget.go`、`changes.go`、`main.go`。
