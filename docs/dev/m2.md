# M2 单机集成（Compose：能给每人起 DSH）

用 Docker Compose 把 platform（iam+org+workspace combined）、edge、NATS、PostgreSQL、节点代理（Docker 驱动）串起来，端到端验证：登录 → 冷启动 → 经 edge 访问实例 → 闲置回收 → 闹钟唤醒。

本机 **Windows 开发机通常没有 Docker**；完整栈以 GitHub Actions（`e2e.yml`）为准。有 Docker 的 Linux 可按下面步骤本机跑。

## 组件与端口（本机 / CI，host 网络）

| 组件 | 地址 | 说明 |
|---|---|---|
| PostgreSQL | `127.0.0.1:15432` | 库 `auriga`；角色见 `deploy/compose/postgres/init.sql` |
| NATS | `nats://127.0.0.1:4222` | JetStream；平台 / 路由写 / edge 会话+路由读 |
| 本地镜像仓库 | `127.0.0.1:5000` | 推送假 DSH |
| platform | `127.0.0.1:8081` HTTP，`7443` 节点 gRPC/TLS | `combined,dev` |
| edge | `127.0.0.1:8080` | `allowLocalIngress=true`；unix 入口 |
| 节点代理 | host 网络 + Docker socket | 单机 ingress：`/var/lib/auriga/agent/ingress.sock` |

公开仓示例 Host：`portal.example.com` / `admin.example.com` / `<id>.i.example.com`（经 edge，无需真实 DNS，请求带 `Host` 即可）。

## DSH 运行时

**测试用极简假 DSH**（`deploy/compose/fake-dsh`）：Node HTTP，提供 `/_auriga/health` 与身份头校验，**不是** S4 真实 DSH 离线包。报告与 PR 说明里已标明。生产用 S4 制品时替换模板里的 `image` / digest 即可。

## 本机步骤（Linux + Docker）

```bash
cd deploy/compose
chmod +x scripts/*.sh
./scripts/prepare.sh          # 起 registry、推假 DSH、生成 PKI/模板/edge 配置 → var/
set -a; source var/compose.env; set +a
docker compose --env-file var/compose.env up -d --build
# 等 platform healthy 后：
AGENT_VOLUME=/var/lib/auriga \
  ENROLLMENT_FILE=var/enrollment/emergency-enrollment.json \
  JOIN_TOKEN_FILE=var/join/token \
  node ../../e2e/m2.mjs
docker compose --env-file var/compose.env down -v
```

应急凭据只写在 `var/enrollment/emergency-enrollment.json`（勿提交、勿贴日志）。

## 端到端脚本（`e2e/m2.mjs`）

顺序：

1. 应急账号登录管理台（Host=`admin.example.com`）
2. 将 workspace 策略 `idleMinutes` 调到契约下限 5
3. 签发入网令牌写入 `join/token`，等待节点出现在 `/admin/nodes`
4. 门户登录后 `POST /me/instance/open`，等到 `ready`
5. `GET /open/<id>` 换票后访问实例 Host，断言假 DSH 响应
6. 用实例令牌发全 0 心跳；写 `ops-cron/store.json` 闹钟；等待闲置回收与唤醒
7. 会话吊销接口冒烟

任一步失败会打印步骤名与响应摘要。

## 节点证书（serverAuth）

workspace NodeCa 签发节点证时带 **clientAuth + serverAuth**（E2）。edge 校验 serverAuth。

**E2 之前入网的旧节点证书缺 serverAuth，必须续期或重新入网，并重启 agent 入口。**

Compose 里 platform 的 `AURIGA_IAM_JWK_SET_URI` 指向 `http://127.0.0.1:8081/oauth2/jwks`：`issuer` 仍是虚拟 Host，资源服务器必须经 loopback 拉 JWKS。

## 已知限制

| 项 | 说明 |
|---|---|
| 假 DSH | 无真实插件 / Cordis；心跳由 e2e 代发 |
| 闲置下限 | 契约 `idleMinutes` ≥ 5，整段 e2e 约需 10+ 分钟 |
| host 网络 | Compose 为单机设计；多机需改 ingress TCP + 通告地址 |
| 凭据 | `deploy/compose` 内口令仅为 e2e 占位，禁止用于生产 |
| 本机无 Docker | 以 CI `E2E M2` 工作流为准 |
