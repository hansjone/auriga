# 插件市场字段与统计口径

以下字段适用于同租户、当前成员有权看到的已发布插件。版本元数据、成员点赞和运行观察随同资源数据保存，可用于后续筛选和统计。

## 市场列表

- **作者**展示发布版本对应的提交人姓名。服务端保存稳定的作者账号 ID 和送审时的展示名快照，以 ID 筛选。清单里的作者署名可另外显示在详情页，审核和禁止自审自发始终使用服务端认定的主体。
- **作者部门**取送审时平台可信组织资料，随提交人快照一起保存。若有稳定部门标识，筛选使用标识，页面展示当时的名称。没有可信资料时标记“未提供”。历史版本保留当时归属。
- **时间**在列表显示“最近发布”，取当前可见版本的服务端发布时间。详情页可列首次发布时间、各版本发布时间。草稿修改和重新送审均不改变列表时间。
- **版本**展示当前对该成员可见的已发布语义版本。成员已安装版本另列。兼容性使用对应版本清单的 DSH 版本范围，可按“适配当前 DSH”筛选。撤销、停用和分发可见性沿用市场规则。
- **简述**是一句话说明插件做什么。取该已发布版本经过审核的 description，列表可截断，详情显示全文。
- **功能标签**支持每版最多五个，使用小写英文标识，例如 `data-analysis`、`documents`、`operations` 和 `collaboration`。作者通过对话工具或管理台上传表单填写，标签随签名清单送审。旧包的标签列表默认为空。
- **安装数**按包跨版本统计本租户中平台已经确认安装的目标。一个桌面设备计一，一个云端 DSH 实例计一。升级、回滚和重复回执沿用同一目标。卸载确认后减一。禁用状态仍保留已安装副本。桌面沿用现存有效回执，云端用随后收到的有效观察补齐，因此旧插件的初始数值可能偏低。
- **星标（点赞）**按包统计，每个租户成员对同一包最多一星，可撤销。服务端以租户、成员、包三者唯一，使用“设置已点赞／取消点赞”表达目标状态，使重复请求幂等。升级沿用原包的星数，市场仅返回总数与当前成员是否已点赞。

## 搜索、筛选与排序

搜索覆盖名称、简述和功能标签。列表可按作者、作者部门、功能标签筛选，并按最近发布、安装最多或点赞最多排序。相同排名使用包 ID 确定次序。详情展示 DSH 兼容范围及版本权限。当前 IAM 部门资料只有可信显示名称，筛选使用快照中的名称。

先按租户和成员授权确定可见包与版本，再计算筛选项、结果和排序。安装数、点赞数、当前成员星标和发布时间来自平台。操作人身份、所属部门和统计字段均不作为对话工具的可写参数。
