# 托管实例网络设备凭据

独立的模型 Key 与原生模型配置见 [托管模型凭据](managed-model-credential.zh.md)；下文网络凭据不增加模型权限。

IAM 是唯一签发方。workspace 经受认证内部接口提交 tenant、成员 account、instance 与凭据代次；IAM 核验活跃账号及成员后登记类型为 managed 的设备。每个实例仅保留一个当前代次。凭据是独立随机机密，IAM 保存核验散列及按租户/实例/代次隔离的加密重试副本，不能以实例控制令牌替代。设备访问令牌仅含桌面网络所需的设备权限，不附加管理员、实例或模型权限。

契约新增内部托管凭据签发/吊销接口、外部换取接口及节点 Secrets 字段。网络是附加能力：永久拒绝记录 disabled/permission_denied 后照常无网络启动；暂时失败最多等30秒后先启动，后台每30秒有界探测，材料到位后排重启下发。Instance 的 managedNetworkState/Reason 供查询。workspace 把凭据经现有 HPKE 封装与规格一起下发；agent renderer 解密后原子写入实例材料目录的 0600 文件，以 `AURIGA_DEVICE_CREDENTIAL_FILE` 传递路径。平台 URL、网络安装信任根等非机密材料沿可信渲染配置下发，机密不进入环境变量、镜像或日志。

managed 插件从文件读取凭据，以专用 managed-device grant 向既有 `/oauth2/token` 换取最长300秒设备 Bearer，并在到期前续期。凭据最长30天，到期后拒绝，重启轮换。通过同一 `createDeviceProvider`、network lifecycle/runtime、原生宿主适配和 consent 接线注册/取票、入网和发送；入网成功仅在严格 READY 后返回，发送沿用同一运行时状态门禁。凭据核验失败才计入租户、实例与可信edge客户端IP失败桶，正确凭据不受失败桶影响；429时沿用尚未过期Bearer并退避，到期仍失败才撤工具。其他核验失败关闭旧代，迟到结果不能恢复旧代。

换票错误码：仅在随机材料散列及租户、成员、实例、设备归属核对通过之后，设备或材料撤销、材料过期、成员移除/禁用或网络权限撤回、实例删除/停止或代次绑定失效、后端会话失效统一返回 HTTP 403 `network.revoked`；不计入未验真失败桶，客户端永久拒绝同材料并提示从门户重新进入。未验真材料（错误/缺失凭据、未知设备、错租户/成员/实例、格式错误）返回 `common.forbidden` 并按原阈值计失败桶，桶满仍返回 429 `common.rate_limited`。换代后旧散列已被替换或权威记录已清理时，旧材料无法再验真，同样返回通用拒绝。权威查询故障返回 503 `common.unavailable`，保持失败封闭并允许退避；普通 401/403 不证明永久撤销。JWKS 是公钥发现入口，不构成材料撤销权威；托管续期重复使用此 grant，不签发 refresh token。

实例停止/删除时 workspace 使当前代次失效；重启签发新代次，旧凭据及旧访问令牌不能再取得网络票据或通过连接在线核权。用户自助会话列表/撤销和凭据变更跳过托管会话；托管后端会话单独失效时workspace换代重签，管理员设备吊销及成员移出仍失败关闭。令牌换取与网络核权同时检查实例当前绑定/运行意图，跨租户、错误成员或实例一律拒绝；故障时失败封闭。

风险边界：按用户决定，同机隔离整体推迟。DSH 工具可能读取凭据文件，0600 只限制其他 OS 用户，不能隔离同一实例中的工具；本任务不以目录分区冒充安全隔离。文件权限、服务身份、租户隔离、成员权限、代际检查与吊销边界仍强制执行。真实双端互发由 CLOUD-DESK 接续验收。


### 临时认证失败

普通 HTTP 401/403（含 edge 非撤销拒绝）及 JWKS 拉取失败不能证明托管材料已撤销。插件在认证拒绝期间关闭身份准入与消息工具，状态为 unavailable（连接中断/重试中），不排队冒充发送成功；按指数退避重试同一材料，间隔最多 30 秒，恢复核验后自动继续。429 保留原有未过期令牌期限的处理不变。只有 IAM 托管 grant 明确返回 `network.revoked`，或托管材料自身到期才永久拒绝同一材料，不自动重试。gateway 的 `network.revoked` 也可能来自 IAM 查询故障超过宽限期：托管插件先关闭连接及身份准入，再退避向 IAM 重新换取凭据，由该 grant 结果裁决；IAM 暂时不可用则继续退避，正常后自动重连。短期访问令牌过期本身只关闭准入，仍可按正常 grant 重新核验。JWKS 的错误码不用于撤销材料。

成员撤销、实例删除若仅返回通用 OAuth/HTTP 拒绝码，插件只能保持失败封闭并退避；服务端需提供可区分的权威撤销信号后才能永久拒绝。诊断只记录 trace、分类与安全状态，不记录响应正文、凭据或令牌。
