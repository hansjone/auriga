# 进度

> 只记任务编号、状态和结论。计划见 [roadmap.zh.md](roadmap.zh.md)。

交付目标是让公众按公开流程自行部署；NAS 用于真实环境验收。通用安装、制品、签名和配置能力应在公开仓库可复现，现场参数与凭据单独配置。域名访问和内网纯 IP 访问都须完成登录、管理台、实例 HTTP/WebSocket 及会话边界验收；现有局部回退代码不等同完整支持。
