# 进度

> 只记任务编号、状态和结论。计划见 [roadmap.zh.md](roadmap.zh.md)。

交付目标是让公众按公开流程自行部署；NAS 用于真实环境验收。通用安装、制品、签名和配置能力应在公开仓库可复现，现场参数与凭据单独配置。域名访问和内网纯 IP 访问都须完成登录、管理台、实例 HTTP/WebSocket 及会话边界验收；现有局部回退代码不等同完整支持。

界面分工：管理台为独立 Vue 应用；DSH 插件按原生登录、功能、设置三部分开发，复用宿主控件、字体和主题色彩，支持独立轻量安装。功能优先级与布局依据[管理台需求复核](../design/auriga-admin/requirements-review.md)和[插件设计](../design/auriga-plugin/README.md)，插件外观以 DSH 系统为准。插件原生登录接线、真实总部连接及完整资源安装仍待后续交付，不能用页面或原型代替业务闭环。
