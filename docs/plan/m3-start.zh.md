## M3 先定契约，再拆实现

当前正式契约覆盖 iam、org、workspace、节点、插件等底座，尚未定义完整的模型网关、资源中心、知识及出网接口。

C2 先产出 M3 契约草案，仅写设计文档，可与 W2V 并行。优先明确 G1 模型网关和 R1 资源中心的接口、权限、错误码、事件、租户与凭据边界；再列出 G2 MCP 网关、N1 知识、X1 出网、F1 文件、P2 团队面板的依赖。

主控审查草案后形成正式契约变更，再派 G1/R1 的小型实现任务；架构偏离、契约大改和付费服务先交用户决定。草案完成不等于实现开工。

第一批实现使用本地假上游和测试制品，不调用付费模型，不改真实部署。任务说明明确各自路径，避免多个工人同时修改契约、公共组件和装配代码。
